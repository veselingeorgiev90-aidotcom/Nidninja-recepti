# Моята кухня с Ninja OL750EU

[Отвори списанието](https://veselingeorgiev90-aidotcom.github.io/Nidninja-recepti/)

Разлистващо се списание с търсене по ястие, продукти, програма и приставка.

## Поддръжка

- `index.html`: корица, структура и единният списък с рецепти.
- `app.js`: разлистване, търсене и директни адреси като `#recipe-16`.
- `styles.css`: оформление за телефон, компютър и печат на текущата рецепта.
- `images/`: изображенията на рецептите. Името на всеки файл съответства на номера на рецептата; пътищата са относителни към сайта.
- `ninja_cover_new.jpg`: одобрената корица.

Снимките са илюстрации на ястията. Обновяването от 11.10.2026 запазва 22-те съществуващи рецепти и корицата, извежда първите 7 вградени изображения в отделни файлове, добавя 14 изображения, създадени с Imagegen, и вече одобреното изображение на Маргарита. Новите изображения са в единен фотографски стил: конкретното ястие, топла естествена светлина, дървена маса, без текст и лога.

## Нови рецепти

Нова рецепта се публикува само след изрично одобрение от собственика. Съществуващите workflows подготвят предложение за преглед; не го сливат автоматично. Изображението трябва да е качено в `images/` преди подаване на рецептата. Форматът на `image` е например `images/recipe-23.webp`.

Автоматичните проверки валидират списъка с рецепти, дублираните имена, наличието на изображения и JavaScript синтаксиса. GitHub Pages публикува от `main`; `.nojekyll` запазва статичното обслужване.
